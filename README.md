# Dossier recevable

Version 0.1.0 — ELY Mustapha — 9 novembre 2026.
Skill Claude de contrôle documentaire des candidatures et offres de consultants.
Même esprit que Free Africa : preuves traçables, incertitudes explicites, protection des données et livrables exploitables.

## Promesse
Transformer un dossier dispersé en exigences vérifiables, preuves, corrections et points à arbitrer. Aucune garantie de recevabilité, d’attribution ou d’exhaustivité. Aucune affiliation institutionnelle. L’originalité commerciale n’est pas établie.

## Installation
Dans Claude Code, copier le dépôt dans .claude/skills/dossier-recevable/ du projet autorisé. Pour l’import dans une interface Claude compatible, créer une archive ZIP contenant un dossier dossier-recevable avec SKILL.md à son premier niveau, ainsi que references, assets et scripts. Vérifier la structure de l’archive source GitHub avant import. La disponibilité des skills dépend de votre environnement.

## Utilisation
« Utilise Dossier recevable sur les TDR, mon CV, les formulaires et mes offres joints. Produis le registre des exigences avec preuves, les blocages, les corrections et la checklist. N’invente aucune information manquante. »

## Contenu
SKILL.md : instructions ; references/ : protocole, finances et sécurité ; assets/ : modèles ; scripts/ : calculs locaux sans réseau ; tests/ : cas fictifs et tests ; guides : utilisation et limites.

## Validation
Les tests Python vérifient uniquement l’arithmétique. Les scénarios Claude sont à exécuter dans votre environnement avant usage sensible. Le rapport de validation distingue ces deux niveaux ; aucun benchmark utilisateur ni certification institutionnelle.
